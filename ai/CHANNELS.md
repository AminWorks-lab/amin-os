# 应用 AI 渠道

在「AI 设置 → 应用渠道」为各应用选择生成方式，修改后点击对应应用的「保存应用渠道」。回复选项（候选生成与草稿扩写）、世界状态、地图、势力概览、能力面板、信息面板、剧情档案、人物关系、人物卡、背包与账本、场景与时间及联合初始化可以分别配置。刷新酒馆配置列表会保留尚未保存的选择。

## 三种生成方式

| 方式 | 接口、消息与预设 |
| --- | --- |
| Amin 独立接口 / 共享异步预设 | 使用 Amin 的全局或命名 API 配置，浏览器直连接口；消息按 Amin「异步预设」及应用任务要求组合。 |
| 酒馆当前配置 · 完整预设 | 调用酒馆 `generateQuietPrompt`，由酒馆按 Quiet 触发规则组合当前聊天上下文与完整提示词预设；Amin 提交本次工具任务。 |
| 指定酒馆连接配置 · 采样参数 | 通过酒馆 `ConnectionManagerRequestService` 请求指定配置，使用其接口、模型及生成参数。消息由 Amin 组合，不加入该配置完整的 Prompt Manager 提示词栈。 |

两种酒馆原生路由均不切换主聊天的连接。它们需要当前酒馆版本暴露对应接口；不可用的选项会禁用并显示原因。指定配置必须明确选择后保存；配置删除、停用或变化时会报错，不静默改用其他渠道。

Quiet 的提示词块及扩展是否生效由酒馆的 Quiet 触发规则决定，因此不承诺与正常正文生成的最终提示词完全相同。它会等待当前正常生成结束，并与其他 Quiet 任务依次执行。取消只让 Amin 停止等待和采用结果；宿主已开始的 Quiet 调用可能继续完成。排队期间聊天、连接或预设变化会阻止采用陈旧任务。

## Amin 独立 API 配置

1. 在「API 连接」选择读取酒馆连接后直连，或手动填写接口、模型和密钥；可拉取模型列表，也可手动输入模型名。
2. 填写配置名称，点击「保存为新配置」。每份配置独立保存模型、请求参数、输出限额与任务策略。
3. 在「应用渠道」选择 Amin 路由及所需配置，点击「保存应用渠道」；「跟随全局默认」使用共享设置。

Amin 的“读取酒馆配置后直连”仍属于独立 API 路由，需要读取可用密钥及接口允许浏览器跨域；它与两种酒馆原生路由不同。选择配置编辑时会把它载入全局设置。更新保存配置影响绑定它的应用；删除配置后，这些 Amin 绑定恢复跟随全局默认。只修改全局设置不会重写其他已保存配置。

密钥默认仅在当前页面会话保留；勾选「记住密钥」后才在当前浏览器保存。绑定只保存配置 ID，不复制密钥。自定义 requestBody 属于 Amin 独立 API 配置，不覆盖酒馆原生路由。

## 任务与应用关系

回复选项的候选生成与“根据草稿扩写”共用回复选项渠道。独立改写草稿已移除；遗留文风转换渠道仅作兼容保留，不控制当前回复选项请求。信息面板的资料生成与模拟推演共用信息面板渠道；编年史起草与档案资料生成共用剧情档案渠道。五个资料应用的单模块生成使用所属应用渠道，勾选多个模块后使用“联合初始化”渠道。世界状态的「按现有剧情更新状态」也使用世界状态渠道：选择已有聊天楼层生成可编辑建议，预览并确认后才保存，不加入联合初始化。场景时间与骰子的本地操作仍无需 AI。

任务启动时捕获所选渠道和任务资料。切换聊天、来源变化或宿主配置失效时，应用会拒绝陈旧结果。任务记录显示渠道与请求预览：Amin 直连显示覆盖 requestBody 后的内容，指定酒馆配置显示 Amin 组装消息；Quiet 只展示提交的工具任务，最终完整请求由酒馆组装，不能在此完整预览。

语音朗读使用独立语音协议，其 MiMo、火山引擎及本地服务在语音应用内设置。世界书管理不调用生成 API。

这些接入有离线服务与界面回归测试；真实酒馆版本的接口支持、供应方返回、完整提示词效果及取消时序需在目标宿主验证。

## 实现位置

渠道选择、任务记录与请求预览在 `ai/service.js`；Amin 独立接口的传输、配置校验与排队在 `ai/transport.js`，异步预设在 `ai/presets.js`，两种酒馆原生路由在 `ai/host-generation.js`。各应用的结构化任务经 `ai/task.js` 的 `runTask` 发起（捕获渠道 → 生成 → 取消与陈旧检查 → 判空 → 解析），模型输出由 `ai/json.js` 的 `parseModelJSON` 统一解析：容忍代码围栏、BOM 及前后说明文字，只取第一个完整 JSON 对象或数组。解析失败时 `runTask` 会附上错误说明再请求一次，仅重试一次；供应方报错、取消、陈旧结果和空内容不重试。地图、世界状态与回复选项也只经共享层请求，不再自带直连或 generateRaw 后备。
