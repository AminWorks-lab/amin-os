# 规划与验收

## 本轮已实现

功能融入现有应用，没有新增独立插件。下列“已实现”指代码和入口已提供，不代表真实设备、模型及同步性能已完成验收。

| 入口 | 当前能力 | 边界 |
| --- | --- | --- |
| 设置 → 剧情文件存储 | 只读检查楼层／Swipe 索引、分支来源、状态可读性及索引／状态文件大小分类 | 仅检查当前聊天可达数据；不是整个扩展存储的空间清理器 |
| 同页 → Amin 性能诊断 | 手动开始／停止测量恢复、宿主保存、扩展文件读写的次数与耗时、估算 JSON 字节数 | 默认不开启，仅当前页面内存记录；不是 TT 全局性能或实际网络流量测量 |
| 世界状态 → 联动更新 | 最近最多 12 条本次运行的变量变化与原生错误记录，查看前后差异 | 刷新或切换聊天清空；只是观察到的快照，不能证明全部模型指令已执行完毕 |
| 能力面板 → 行动结算 | 治疗／休息／旅行草稿模板，明确选择消耗、数值变化、固定骰点和耗时；可关联任务进度与逐项配置奖励，整批预览确认 | 保存重试不重复结算；领取收据随剧情状态保存，当前状态已领取不可再领；不解析奖励说明、不推断完整游戏规则；旅行模板仅推进时间，不自动移动地点 |
| 人物卡 → 人物关联总览 | 读取持有资产、人物关系、记忆、场景位置和日程 | 只读汇总，由原应用管理数据；能力目标仍是自由文本，不按同名猜人物绑定 |
| 剧情档案 → 任务／线索 | 记录任务目标、进度、线索来源、可信程度与任务关联；AI 建议支持 `save-task`／`save-clue` | 保存任务或线索不自动完成任务、发奖或修改背包 |
| 联动更新 → AI 资料预算与固定保留 | 默认关闭的字符预算及独立条目筛选；可固定模块或具体条目，依据当前场景明确 ID 关联选择，显示条目纳入／省略理由 | 先执行隐私投影，再筛选只读条目；可写模块、生效能力和已启用档案引用完整保留，固定条目及其依赖不被预算静默舍弃；无有效关联时保留原投影 |

预算只限制 Amin 注入的剧情资料字符数，不是 token 上限，也不含世界书更新规则。固定保留不会绕过模块的启用与读取权限；场景关联不靠人物名字猜测。提示词资料已发送也不保证模型遵循。

## 既有存储与回复流程

- 历史状态外置保存；聊天索引按稳定消息标识与 Swipe 关联存档，分支共用历史状态文件。见[存储说明](story-chat-index.md)。
- 回复选项使用生成候选／设置两页，用户发送后清空临时候选；文风、内容风格和提示词集中管理。见[回复选项](../apps/reply/WRITING.md)。
- 跨设备必须同时同步聊天文件与扩展存储。正文编辑保留原状态，不推断变量变化。

## 代码与流程整理

- 联动权限、模块列表和提示词构建复用本次调用中已校验的设置，避免每检查一个模块就重复深拷贝整份设置。没有跨聊天或跨调用缓存，之后的读取仍使用最新配置。
- 人物卡、背包和剧情档案共用 `ui/forms.js` 的表单结构；业务校验、草稿、保存锁和事件仍由各应用管理。新表单优先复用这套控件，契约见 [UI 说明](../ui/README.md)。
- 外置状态图在保存／导入已有节点时复用刚读到的文件，继续校验内容哈希和父链。重复保存一个差量节点的测试由 3 次读取减少为 2 次；两节点导入由 5 次减少为 3 次。该结果是存储适配器调用计数，不是实际手机耗时。
- 存档格式和聊天／Swipe 索引不变，无需迁移。保存前准备、聊天切换检查和写入后校验继续保留；精简不改变重试或分支恢复的顺序。
- 存储进一步复用同次保存的已验证准备结果；索引保留完整身份扫描但只复制变化消息与末尾行；迁移／历史检查按批次共享有上限的父链读取缓存。实现与边界见[保存与读取优化](story-chat-index.md#保存与读取优化)。

## 后续优先级

1. **真实 TauriTavern 验收**：快速切换聊天、继续生成、重新生成、删楼、历史分支、双向设备同步；测量 Amin 的恢复、保存和读写开销，再依据数据优化。
2. **永久空间清理**：已提供宿主可枚举范围的全库占用分析、引用检查、候选预览和只读备份导出。TT 2.3.0 公开接口不能证明遗留目录覆盖或提供全局写入／同步锁，因此永久删除尚未开放；需宿主维护事务或经过验证的离线流程。见[全库分析](STORY-LIBRARY.md)。
3. **更完整的规则配置**：当前模板仅填当前草稿，奖励需逐次选择已有资源；后续可考虑用户保存自定义规则模板、路线移动、检定结果分支。任务完成仍不靠关键词自动判定。
4. **资料选择实际效果验收**：条目筛选已接入，后续对比真实请求的字符量和剧情连贯性。当前允许变量更新的模块保持完整；不通过裁剪必要资料换取字数下降。

## 交付证据

分别记录静态检查、自动测试、模拟浏览器和真实宿主验证；未运行的层级保留待验收。具体测试数量以对应提交运行结果为准，不用历史数字代表当前版本。性能诊断提供测量工具，本轮未据此完成用户设备的性能实测。
