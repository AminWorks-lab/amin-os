# 当前变量与最近五份备份

> **历史参考。** 本文描述的存储或运行时已在 0.18 移除，现行代码不再执行；仅保留用于理解和导入旧聊天资料。现行说明见[独立剧情状态指南](../INDEPENDENT-STORY-STATE.md)。

0.17.4 的简洁存储只保存当前剧情变量和最近 5 份备份。支持 TauriTavern 扩展文件接口的新聊天默认使用此模式；已有旧索引聊天继续保留原模式，需要用户明确切换。旧索引模式的楼层与 Swipe 恢复说明见 [旧剧情文件存储](STORY-FILE-STORAGE.md)。

## 入口与选择

打开 **Amin OS → 设置 → 剧情存储**，页面标题为「剧情文件存储」。

| 操作 | 结果 |
| --- | --- |
| 改用简洁存储（保留当前变量） | 核验并保存此刻的受管变量，改用当前记录；不依赖旧 Swipe 标识，也不从旧正文猜测变量。 |
| 备份并清空当前变量 | 先展示清空范围；点击「确认备份并清空」后，保存清空前备份，再清空受管变量及其规则。旧索引聊天也会切换为简洁存储。 |
| 查看最近备份 → 恢复所选备份 | 明确把所选备份应用为当前变量，并保留恢复前状态。不会回退聊天消息。 |
| 导出当前聊天剧情备份 | 下载本聊天的当前记录，包含当前状态、最近备份和校验信息。 |
| 导入变量备份 → 重新载入当前变量 | 导入先核验同一聊天的记录并写入文件；不会自动覆盖正在运行的变量。重新载入才应用文件中的当前状态。 |

「刷新状态」只刷新显示。「统计当前聊天占用」按需读取当前记录；显示 JSON 内容字节数，不表示磁盘实际占用或同步流量。

## 保留的状态与取舍

每个聊天使用 `amin-os / story-current-v1` 中的一个可覆盖记录，保存一份当前状态及最多五份最近备份。变量实际变化时保存新当前状态，旧当前状态进入有限备份列表；相同状态不会不断增加相同备份。文件和每份快照均校验完整内容。

**五份是数量上限，不是固定字节数。** 人物、背包等资料变多时，每份快照也会变大。整个记录的序列化 UTF-8 内容上限为 32 MiB；超限会报错，不静默截断状态。这个上限只针对当前记录，既有旧索引、历史文件、宿主聊天备份、媒体和另行保存的命名存档仍可能占用空间。

此模式没有逐楼层或逐 Swipe 状态。切换回复候选、删楼或复制分支不会回到那个时间点的变量；复制的分支沿用当前状态，并按新的聊天身份建立独立当前记录。如果故事改成另一条路线，需要手动更新当前资料、恢复仍在最近列表中的备份，或先备份后清空并重新生成。旧楼层状态按钮不提供原状态快照。

小白 X 变量 2.0 仍执行本轮 `<state>`，Amin 应用继续读取和编辑当前变量。简洁存储接管的是状态保留方式，不代表停用模型更新或当前资料编辑。聊天元数据仍保留运行所需变量；使用此模式不意味着聊天文件只剩一个短引用。

## 原生变量面板的兼容限制

已安装的小白 X 源码审查显示，其变量面板直接编辑或删除变量时没有稳定的来源事件。简洁存储在导航保护期间无法可靠区分这种手动改动与旧楼层状态回填，因此直接修改本模式受管的 11 个变量根的内容可能被撤回。

当前模式请通过 Amin 各应用编辑或重建受管资料；无关变量根不受这项导航保护。此限制依据已安装源码审查，尚未通过真实宿主变量面板操作验证。

## 备份后清空的范围

清空范围仅为当前聊天中的以下 11 个受管变量根及其对应规则：

- 人物、背包、关系、场景、剧情、持续效果、地图、信息和骰子，即九个 `AminOS…` 根。
- 世界状态 `状态栏` 与势力 `势力资料`。

清空后相关应用的当前投影同步为空，并协调受管原生记录，避免旧数据立即回填。聊天正文、回复候选、无关变量及规则、全局能力库、世界书和 API 设置保留。清空不会清理宿主全部元数据，也不删除其他聊天。

清空前必须成功保留备份；文件写入、校验或原生应用失败时报告错误。生成、恢复或保存尚未完成时不能执行清空和恢复。选择预览之后，若聊天、候选、变量或规则已变化，需重新核对范围或备份列表。

## 故障处理

| 提示 | 处理方式 |
| --- | --- |
| 扩展文件存储不可用 | 检查宿主是否提供兼容的 `api.extension.store`，并等待初始化完成。本模式不以浏览器缓存冒充已保存的外置记录。 |
| 当前状态文件缺失 | 在源设备导出同一聊天的简洁存储备份，导入后点击「重新载入当前变量」。 |
| 当前状态或备份校验不一致 | 保留原文件。使用已核验、属于同一聊天的备份恢复；无法确认旧文件归属或无法读取它时，不会盲目覆盖。 |
| 备份属于另一条聊天／文件不是当前状态备份 | 选择此聊天导出的简洁存储 JSON。旧索引图备份及原聊天 JSONL 不是此模式的变量备份。 |
| 当前记录已被修改 | 重新读取状态和最近备份，再核对操作；不要连续提交旧预览。 |
| 保存失败／变量加载未完成 | 保持当前聊天，查看具体错误。不要重复执行消耗或结算；处理文件问题后重新载入，或明确选择备份清空。 |
| 旧索引模式仍报重复 Swipe | 需要历史回退时使用旧模式的原聊天校验；只需继续当前剧情时，可核对当前变量后显式改用简洁存储。切换不会推断或修复已经丢失的剧情资料。 |
| 同步后仍提示人物、关系、场景、剧情档案未同步 | 0.17.5 修复了字段顺序和默认字段引起的误判。先更新插件并重新加载；这条误判不需要清空变量或重新生成资料。更新后若仍有提示，应核对真正未同步的内容。 |

写入前会读取并比较完整旧记录，同一运行环境的同键写入互相排斥，写入后等待回读核验。**这不是跨设备原子比较写入（CAS）**：宿主没有提供该事务接口。另一设备可能在比较与写入之间修改文件；回读也不能证明不存在所有同步冲突。两端同时编辑同一聊天时仍需人工核对，不以本地校验成功宣称跨设备合并成功。

## 手机同步与验证边界

电脑与手机都需安装支持此模式的 Amin OS 和兼容的小白 X 变量 2.0。TauriTavern 同步范围需同时包括相应聊天历史与扩展存储 `extensions.store`；仅同步聊天会缺少当前记录，仅同步外置文件则缺少对应聊天和模式标记。

手动迁移时，同时保留该聊天文件和它导出的简洁存储备份。在目标设备打开同一聊天、导入变量备份，再明确重新载入。备份是当前状态加有限恢复点，无法借它恢复已经淘汰的旧楼层或旧 Swipe。

自动测试覆盖记录校验、有限备份、保存和恢复失败、聊天变化保护及当前状态应用；它们不代表真实手机文件同步、网络中断或宿主冲突解决已经实测。固定文件键和有限备份控制此模式新增的记录数量，不保证同步传输量固定，也不保证每次保存只传输变化字段。

## 旧文件保留

切换不会删除旧聊天、旧索引或 `story-v2` 外置文件，也不会自动删除可能被其他分支共享的状态。旧文件是否可以删除，需要独立确认所有引用及备份覆盖范围；不能仅因为当前聊天已改用简洁存储就视为垃圾。简洁存储也不保证立即缩小原有聊天、宿主备份或媒体文件。
